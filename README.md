# AI System Assistant

A responsive React/Vite starter for the AI System Assistant project.

## Current prototype
- Modern responsive web UI
- AI chat interface with starter intent responses
- Browser-visible network status
- Browser storage estimate
- Browser-reported logical CPU count / device memory where supported
- Microphone permission request
- Permissions page
- Android APK download placeholder

## Run locally
Requires Node.js 18+.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.
